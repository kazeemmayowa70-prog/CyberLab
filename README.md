## About

CyberLab is a hands-on project where I document what I learn in cybersecurity and web development. Each lab is a small browser simulation that I built myself to understand a real security idea.

## Labs

- **Password Security Lab:** checks password length and complexity
- **Authentication Lab:** simulates account lockout after failed logins
- **Networking Lab:** breaks a URL into protocol, domain, port and path
- **Input Validation Lab:** shows safe handling of user input (XSS prevention)
- **Password Hashing Lab:** generates SHA-256 hashes with the Web Crypto API
- **Access Control Lab:** shows role-based permission checks

## Important note

These labs are learning simulations that run in the browser. They are not real security systems. The real server-side versions are in my backend project, linked below.
